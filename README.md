# Academic Portfolio

A portfolio documenting and organizing my recent independent research.

## About

This repository collects and organizes materials related to my independent research. My interests span continental philosophy, psychology, psychoanalysis, economics, analytic philosophy, and political philosophy. Although these fields are presented in separate sections for accessibility, my work frequently moves between them, examining the relationships and shared problems that emerge at their intersections.

The purpose of this archive is to make that work more accessible, coherent, and navigable.
